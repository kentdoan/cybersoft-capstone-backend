# Cybersoft Capstone Backend

Hệ thống kết nối công việc và tuyển dụng (giống Fiverr)

## Thông tin Triển khai (Deployment)

Hệ thống đã được triển khai hoàn chỉnh lên môi trường Cloud để phục vụ việc chấm điểm và kiểm thử:

- **Backend**: Triển khai trên nền tảng Render.
- **Cơ sở dữ liệu (PostgreSQL)**: Lưu trữ trên nền tảng Supabase.
- **Cache (Redis)**: Sử dụng dịch vụ Serverless Redis của Upstash.

## Tài liệu API

Tài liệu chi tiết cho các API được viết bằng Swagger. 
Có thể truy cập tại đường dẫn `/api-docs` trên domain của backend để xem mô tả chi tiết về tham số, phân quyền và payload mẫu.
